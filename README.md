# Granit Kurrumeli – Portfolio

Bilingual (Shqip / Deutsch) portfolio built with React, Vite, Three.js (@react-three/fiber) and lucide-react.
The 3D models (robot arm, smart city, ATM) are built in Blender.

## Develop

```bash
npm install
npm run dev
```

Language: toggle SQ/DE in the navbar, or open `/?lang=de`.
All text lives in `src/i18n.js`.

## 3D models (Blender)

Models are generated by `blender/build_models.py` and exported to `public/models/*.glb`.
The `.blend` files in `blender/` can be opened and edited directly in Blender.

Re-generate after editing the script:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P blender/build_models.py
```

If you edit a `.blend` by hand, export it with **File → Export → glTF 2.0 (.glb)** to `public/models/` with the same file name.
Keep these object names, the website animates them:
- robot_arm: `J1`–`J5`, `FingerL`, `FingerR`
- smart_city: `Rotor0`–`Rotor2`, `Car0`–`Car5`, `Beacon`, `Item0`–`Item3`, `ServoArm0/1`, `Laser0`, `Sensor1Light`, `Water0/1`, `TankGlass0/1`, `PumpRotor`, `Flow0`–`Flow3`
- atm: `Screen`, `CashLight`, `CardLight`

## Deploy to Vercel

Option A – GitHub (recommended): push this folder to a GitHub repo, then on vercel.com → **Add New → Project** → import the repo.
Vercel detects Vite automatically (build `npm run build`, output `dist`).

Option B – CLI:

```bash
npx vercel        # preview deploy (asks you to log in the first time)
npx vercel --prod # production deploy
```
